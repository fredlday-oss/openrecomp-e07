# P18-03 - Causal Device Transcript

## Purpose

Capture deterministic device events actually CAUSED by authentic guest execution
continued past the GPUSTAT wait-poll (P18-02). Produce a causal transcript in
which every event is bound to its sequence number, guest PC, authenticated
source owner, instruction word (fresh decode), decoded instruction, event type,
address/register, value, width, and the relevant causal device state.

This stage builds on the P18-02 continuation. It never replays historical
Phase-17 events as current execution.

## Prerequisites

- Frozen Phase-17 terminal authority (tag/commit/tree as in P18-02).
- P18-00 PASS, P18-01 PASS (STATE_DRIVEN_BIT26), P18-02 PASS (authentic poll exit).
- Committed P17-06R device transcript
  (sha256 d7e222c87726748ced23dd60c2b1ba138625227c984dac587be6a5761695fd3a).
- Private Hercules fixture present and hash-matched (fail closed otherwise).

## Inputs

- .openrecomp-phase18/src/p18_exec_continuation_v1.py (P18-02 overlay + drivers).
- .openrecomp-phase18/src/p18_gpustat_state_model_v1.py (bit-26 model).
- .openrecomp-phase17/src/p17_side_effects_exec_v1.py + p17_title_exec_emit_v1.py
  (frozen P17-06R emitter/runtime).
- .openrecomp-phase17/src/p17_device_transcript_v1.py (frozen device class).
- Private fixture (read-only, never committed).

## Provenance requirements

- The continuation reuses the P18-02 fail-closed overlay: poll geometry is
  derived from authenticated bytes and the BIT-26 state model stays in force.
- Every event binds to source SHA-256 -> file offset -> guest PC -> word ->
  fresh decode -> execution record via (a) the owning-instruction provenance
  digest and (b) an independent fresh-decode verification of the authenticated
  private source word (frozen decoder + canonical checked-equality). The raw
  instruction word remains private (P17-06R private mapping); it is bound by
  its committed provenance digest.
- The causal device-state snapshot is emitted by the runtime itself at each MMIO
  event (never reconstructed in Python), and must match the event stream exactly
  (address, width, value, owner, direction).

## Bounded limits

- P17-06R declared budgets unchanged (continuation 8192, total +8192+64).
- Discovery bounded (max 12 emissions) and deterministic.
- Causal device-state snapshot log bounded (4096 entries); overflow fails closed.

## Implementation boundary

- New module .openrecomp-phase18/src/p18_causal_transcript_v1.py and a new gate
  tools/test_phase18_causal_transcript_v1.py. No shared-layer or Phase-17 tree
  changes.
- The module layers a second fail-closed overlay on top of the P18-02 overlay:
  it inserts a causal device-state snapshot log into the frozen runtime and
  parses it back into the causal transcript. No title-specific constants.

## PASS conditions

- Official gate run twice: exit 0, empty stderr, byte-identical stdout (raw and
  LF), identical evidence artifacts.
- Every transcript event carries sequence, guest PC, owner provenance digest,
  decoded instruction, fresh-decode verification, event type/class,
  address/register, value, width, and causal device state.
- Causal device-state snapshots (runtime-emitted) match the event stream 1:1.
- Reached categories are listed; unreached categories are explicitly
  not-reached (never silently treated as a valid no-op when proof depends on
  them).
- Negative controls fail closed.

## FAIL conditions

- Any check failure, non-zero exit, non-empty stderr, or non-identical dual-run
  output/artifacts.
- Hard-coded title PC/constant; unauthenticated instruction; event without an
  authenticated owner; causal log overflow or count mismatch; replayed events.

## NOT_PROVEN properties

- FIRST_FRAME_READY=NO; initialization / frame / playability / general PS1
  compatibility remain NOT_PROVEN.
- GP0/GP1 command semantics, DMA/ordering-table traversal, VRAM mutation and
  display configuration remain NOT established (P18-04..P18-06).

## Negative controls

- Device event without an authenticated owner rejected.
- Unauthenticated owner PC fresh-decode fails closed.
- Causal snapshot count mismatch rejected.
- Tampered fresh-decode digest rejected.
- Causal snapshot log overflow rejected.
- Zero-fill model (state model disabled): poll not exited.

## Determinism requirements

- Official gate run twice; byte-identical stdout (raw and LF), empty stderr,
  exit 0, identical evidence artifacts.
- Independent fresh-private-root reproduction byte-identical to official
  evidence.
