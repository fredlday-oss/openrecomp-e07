# P18-01 - GPUSTAT Polling Model Investigation

## Purpose

Determine mechanically why authentic Hercules execution remains in the GPUSTAT
wait-poll observed at the end of Phase 17, and whether the Phase-17
ZERO_FILL_RECORDED read model is the binding cause. Establish the minimum
defensible, state-driven GPUSTAT model that lets the authentic poll condition be
evaluated, without hard-coding any title-specific value.

This stage investigates the polling model only. It does not run the guest past
the poll (that is P18-02) and produces no frame evidence.

## Prerequisites

- Frozen Phase-17 terminal authority (openrecomp-phase17-pass /
  d7cc5d09eebde398ca6ff3f3dad8dd5841913b69 / tree
  ad3aa822e5a02905ebc25477f7b6c69d0bffa055).
- P18-00 PASS (control plane, frontier analysis, frozen authority verifier).
- Committed P17-06R device transcript (digest
  d7e222c87726748ced23dd60c2b1ba138625227c984dac587be6a5761695fd3a).
- Private Hercules fixture present and hash-matched (fail closed otherwise).

## Provenance requirements

- The poll PC is taken from the transcript (modal owning instruction), never
  hard-coded.
- The fixture member is authenticated through the frozen Phase-17 main-EXE chain
  (PS-X EXE header -> file offset -> guest address -> fresh decode).
- The owning-instruction provenance digest for the poll PC is recomputed and
  required to equal the digest recorded in the committed transcript.

## Bounded execution limits

- Deterministic, offline analysis only. No guest execution.
- Poll simulation is bounded (16 iterations) and state-independent between
  iterations (the guest only re-reads the register).

## Implementation boundary

- New Phase-18 modules under .openrecomp-phase18/src/ and a new
  tools/test_phase18_gpustat_model_v1.py gate. No shared-layer changes.
- Only GPUSTAT bit 26 is modelled. Unmodelled bits fail closed.

## Required evidence

- poll_condition.json - exact poll condition re-derived from authenticated
  bytes, with provenance digests.
- model.json - minimum state model, coverage boundary, reference sources.
- simulation.json - positive/negative/zero-fill poll simulations.
- negative_tests.json - fail-closed controls.
- RESULT.json, p18_01_tests.json, determinism.json, official_runs.json, run1/2
  logs.

## PASS conditions

- Poll condition derived: lw; nop; and; beq, single-bit mask, branch back to the
  load, exit requires the tested bit set.
- Guest-tested bit agrees with two independent emulator references (bit 26,
  0x04000000).
- State-driven model: idle => bit set; busy => bit clear; matches an independent
  secondary implementation.
- Simulation: exit reachable in one iteration under faithful idle state; not
  reachable under busy state; not reachable under ZERO_FILL_RECORDED.
- Fail-closed: unmodelled bit rejected; tampered provenance digest rejected;
  unknown owner rejected; synthetic loop derives its own bit (anti-hardcoding).
- Dual-run byte-identical stdout and artifacts.

## FAIL conditions

- Any check failure, non-zero exit, non-empty stderr, or non-identical dual-run
  output/artifacts.
- Any hard-coded title PC or title-specific constant used to force the exit.

## NOT_PROVEN properties

- FIRST_FRAME_READY=NO; initialization / frame / playability / general PS1
  compatibility remain NOT_PROVEN.
- The claim that authentic execution actually leaves the poll in the real
  runtime is NOT established here (that is P18-02).

## Negative controls

- Unmodelled GPUSTAT bit (28) rejected.
- Recomputed provenance digest mismatch rejected.
- Owner PC absent from the transcript rejected.
- Synthetic poll on a different bit derives that bit (proves no hard-coding).

## Determinism requirements

- Official gate run twice; byte-identical stdout (raw and LF), empty stderr,
  exit 0, identical evidence artifacts.
