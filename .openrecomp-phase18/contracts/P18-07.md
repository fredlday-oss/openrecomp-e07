# P18-07 - First-Frame Assessment

## Purpose

Mechanically assess whether a **defensible first-frame chain** has been
established by the work of P18-02..P18-06, and promote only the exact
property that is mechanically proven.

This stage is an **assessment and gatekeeping** stage. It fabricates no
traffic, injects no command stream, mutates no VRAM, and renders no image. Its
output is a causal-link ledger with a per-link verdict and a promotion
decision derived mechanically from that ledger.

Because P18-04 (GP0/GP1), P18-05 (DMA/OT) and P18-06 (VRAM/display) each
established their frontier as **UNREACHED**, the honest primary outcome is:

- `FIRST_FRAME_READY=NO`
- `OPENRECOMP_PHASE18_HERCULES_FRAME_PROOF=NOT_PROVEN`

## Anti-vacuity requirement (binding)

An assessment that can only ever answer `NO` proves nothing. This stage MUST
demonstrate that its promotion logic is **capable of promoting**, and that its
`NO` on authentic evidence is therefore a real determination rather than a
stub. Concretely:

- a synthetic link vector in which every required link is satisfied MUST yield
  `FIRST_FRAME_READY=YES` **inside the control namespace only**;
- that control verdict MUST NOT appear in, influence, or be confusable with the
  authentic verdict, and MUST NOT alter any canonical marker;
- the gate MUST fail closed if the control cannot promote.

## The causal-link chain

The chain is evaluated in order. Each link is one of `ESTABLISHED`,
`UNREACHED`, or `NOT_PROVEN`, and every link verdict must cite the evidence
that produced it.

| id | link | evidence source |
|---|---|---|
| L1 | authenticated execution | P18-02 continuation + P18-03 causal transcript, per-PC provenance digests |
| L2 | authentic GPU command operations (GP0/GP1) | P18-04 frontier, `gp0_write_count` / `gp1_write_count` |
| L3 | authentic GPU DMA / ordering-table operations | P18-05 frontier, `dma_access_count` |
| L4 | deterministic GPU state (decoded command semantics) | P18-04 command decode, bounded and provenance-bound |
| L5 | deterministic VRAM effects | P18-06 `vram_display_status`, mutation digest |
| L6 | valid display configuration | P18-06 display-state evidence (display enable / start / mode writes) |
| L7 | coherent displayable framebuffer | P18-06 framebuffer descriptor + digest |

A link is `ESTABLISHED` only when its evidence is **authentic** (bound to real
reached guest execution with owner provenance) and **deterministic** (stable
digests). Control-derived, probe-derived or synthetic evidence can never
establish a link; it may only prove a model is genuine, as in P18-04..P18-06.

## Promotion rule (exact)

`FIRST_FRAME_READY=YES` iff **all** of L1..L7 are `ESTABLISHED`.

Reaching any single milestone is explicitly insufficient. The gate MUST prove
that each of the following, on its own, yields `NO`:

- first GP0 write;
- first GPU DMA;
- first ordering-table packet;
- first primitive;
- first VRAM mutation;
- first display register setup.

Any missing link, any digest mismatch, any unparsable or absent evidence is
fail-closed `NO`, never a default or optimistic `YES`.

## PASS conditions

The stage PASSES when **either** outcome is legitimately established:

1. **NO FIRST FRAME (expected primary outcome)**
   - every consumed frontier document is present and hash-verified against the
     digests above;
   - the ledger records L1 `ESTABLISHED` and each of L2..L7 with its authentic
     evidence and honest verdict (`UNREACHED` / `NOT_PROVEN`);
   - the promotion rule yields `FIRST_FRAME_READY=NO`;
   - the anti-vacuity control promotes in the control namespace, proving the
     assessor is capable of `YES`;
   - every single-milestone anti-inflation control yields `NO`;
   - all Phase-18 claim markers stay `NOT_PROVEN` / `NO`.

2. **FIRST FRAME ESTABLISHED** (only if all seven links are authentically
   `ESTABLISHED` by P18-02..P18-06 evidence)
   - every link cites authentic, provenance-bound, deterministic evidence;
   - the displayable framebuffer descriptor and digest are real and connected to
     authentic title execution and real GPU operations;
   - initialization, frame and playability proofs are recorded **separately**, so
     a frame result never implies playability or general compatibility.

Common requirements: dual official runs exit 0, empty stderr, byte-identical
stdout (raw and LF) and identical evidence artifacts; negative controls fail
closed.

## FAIL conditions

- Any check failure, non-zero exit, non-empty stderr, or non-identical dual-run
  output or artifacts.
- A frontier digest that does not match the recorded value, or evidence that is
  missing, unparsable, or silently skipped.
- `FIRST_FRAME_READY=YES` promoted while any link is not `ESTABLISHED`.
- A link marked `ESTABLISHED` on control-, probe- or synthetic-derived evidence.
- A control-derived or synthetic verdict leaking into the authentic verdict or
  any canonical marker.
- An anti-inflation control that yields `YES` for a single milestone.
- An anti-vacuity control that cannot promote (assessor is vacuous).
- Any Phase-18 claim marker promoted other than by the exact rule above.

## Negative controls

- A frontier document whose digest does not match the recorded value is rejected
  `FRONTIER_DIGEST_MISMATCH`.
- A missing frontier document is rejected `FRONTIER_EVIDENCE_MISSING`, never
  skipped.
- An unparsable frontier document is rejected `FRONTIER_EVIDENCE_UNPARSABLE`.
- A link marked `ESTABLISHED` without a cited evidence provenance is rejected
  `LINK_PROVENANCE_MISSING`.
- A link marked `ESTABLISHED` on control/synthetic-class evidence is rejected
  `LINK_CONTROL_DERIVED_EVIDENCE_REJECTED`.
- Any single-milestone link vector (GP0 write only; DMA only; OT packet only;
  primitive only; VRAM mutation only; display setup only) yields `NO`, asserted
  individually.
- An all-links-satisfied control vector yields `YES` in the control namespace;
  the gate fails closed if it yields `NO`.
- A promotion attempt that skips any link is rejected `PROMOTION_CHAIN_INCOMPLETE`.
- A control verdict that reaches the authentic verdict field is rejected
  `CONTROL_VERDICT_CONTAMINATION`.
