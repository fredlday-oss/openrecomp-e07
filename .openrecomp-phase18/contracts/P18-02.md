# P18-02 - Authentic Poll Exit / Execution Continuation

## Purpose

Use the P18-01 minimum state-driven GPUSTAT model to continue authentic guest
execution past the GPUSTAT wait-poll observed at the end of Phase 17. Prove
mechanically that the authentic guest leaves the poll once the modelled device
state reports command-ready, that every newly executed instruction stays
authenticated, and that the resulting device transcript is caused by the
current execution (not replayed).

This stage runs the guest past the poll for the first time. It promotes no
frame/initialization/playability marker.

## Prerequisites

- Frozen Phase-17 terminal authority
  (openrecomp-phase17-pass / d7cc5d09eebde398ca6ff3f3dad8dd5841913b69 /
  tree ad3aa822e5a02905ebc25477f7b6c69d0bffa055).
- P18-00 PASS, P18-01 PASS (STATE_DRIVEN_BIT26, fail-closed coverage).
- Committed P17-06R device transcript
  (sha256 d7e222c87726748ced23dd60c2b1ba138625227c984dac587be6a5761695fd3a).
- Private Hercules fixture present and hash-matched (fail closed otherwise).

## Provenance requirements

- The poll PC and its branch geometry are taken from the committed P17-06R
  transcript and the authenticated fixture bytes; never hard-coded.
- Every continuation instruction is emitted only after a fresh decode of the
  authenticated private word at that PC (frozen decoder + canonical
  checked-equality), exactly as P17-04R/P17-05R/P17-06R.
- Any newly reached region is authenticated from the read-only source bytes
  before it can be executed; an unauthenticated PC fails closed.

## Bounded execution limits

- The continuation budget and total budget are the P17-06R declared constants
  (continuation 8192, total = recorded-frontier-steps + 8192 + 64).
- Discovery is bounded (max 12 emissions) and deterministic.
- GPU command FIFO depth is bounded (8); the drain rate is one command per
  executed guest instruction.

## Implementation boundary

- New Phase-18 module .openrecomp-phase18/src/p18_exec_continuation_v1.py plus
  a new tools/test_phase18_exec_continuation_v1.py gate. No shared-layer or
  Phase-17 tree changes.
- The module reuses the frozen Phase-17 P17-06R emitter through a fail-closed
  Phase-18 overlay: the frozen generated runtime is post-processed only at
  exact anchors (include line, dispatch loop head, MMIO read/write hooks,
  harness END); any missing or duplicated anchor raises a stable error code.
- Only GPUSTAT bit 26 is modelled. GP0 (0x1f801810) and GP1 (0x1f801814)
  writes enqueue a bounded command; any other MMIO read keeps the Phase-17 zero
  model and is recorded as an unmodelled read.

## Required evidence

- poll_exit.json - derived poll geometry, executions, exit site, and the
  GPUSTAT value the guest consumed at the poll owner.
- gpu_state_model.json - the emitted state machine, read/write counters, and
  the source-level anti-hardcoding proof.
- continuation.json - bounded discovery observations and the authenticated
  region log.
- transcript.json + transcript.sha256 - the causal device transcript produced
  by this execution.
- negative_tests.json - fail-closed controls.
- RESULT.json, p18_02_tests.json, determinism.json, official_runs.json,
  run1/2 logs.

## PASS conditions

- The emitted runtime's GPUSTAT read returns bit 26 as a function of GPU state
  (`pending == 0`), and the literal Phase-17 zero read model is absent.
- Authentic execution enters the poll owner PC and leaves it: the poll branch
  is taken-to-exit (a step whose successor is the fall-through target) within
  the budget.
- The GPUSTAT value the guest consumed at the poll owner has bit 26 set.
- Every executed continuation PC is authenticated (provenance map) and every
  newly reached region is authenticated from source bytes.
- Device events are produced by current execution and every event carries an
  authenticated owning-instruction provenance digest.
- Dual official runs produce identical manifests, runtime results and
  transcripts.
- Negative control: with the Phase-17 zero read model (state model disabled)
  the guest does not leave the poll.

## FAIL conditions

- Any check failure, non-zero exit, non-empty stderr, or non-identical dual-run
  output/artifacts.
- Any hard-coded title PC or title-specific constant used to force the exit.
- Any executed instruction without provenance, or any unauthenticated region.

## NOT_PROVEN properties

- FIRST_FRAME_READY=NO; initialization / frame / playability / general PS1
  compatibility remain NOT_PROVEN.
- GP0/GP1 command semantics, DMA/ordering-table traversal, VRAM mutation and
  display configuration are NOT established here (P18-03..P18-06).

## Negative controls

- Phase-17 zero read model: poll not exited.
- Unmodelled GPUSTAT bit (28) rejected by the state model.
- Tampered poll provenance digest rejected.
- Missing/duplicated overlay anchor rejected (source-level fail-closed).
- Device event without an authenticated owner rejected.

## Determinism requirements

- Official gate run twice; byte-identical stdout (raw and LF), empty stderr,
  exit 0, identical evidence artifacts.
