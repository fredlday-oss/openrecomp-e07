# OpenRecomp is now accepting GitHub Sponsors

**13 November 2026**

OpenRecomp now has a live [GitHub Sponsors page](https://github.com/sponsors/fredlday-oss). Thank you to everyone following, testing and supporting the project.

OpenRecomp is an open-source, architecture-neutral static recompilation framework researching how legacy software can be translated into native code, connected to explicit host runtimes, and checked with reproducible evidence.

## What exists today

The public project includes a versioned intermediate representation, a native ahead-of-time module interface, and bounded validation for published RV32I and MIPS32 fixtures. Deterministic testing and explicit status classifications are core design principles.

**This is not yet a general-purpose game compatibility platform.** The published results are limited to documented test cases, and no blanket claims of commercial-title compatibility or playability are made. Consult [technical status](../TECHNICAL_STATUS.md) and the [evidence model](../EVIDENCE_MODEL.md) for current boundaries.

## What sponsorship supports

- Reproducibility, CI, testing infrastructure and publicly redistributable fixtures
- Additional guest architecture and native-runtime engineering, subject to evidence-based validation
- Documentation and contributor onboarding
- Exploration of **OpenRecomp OS**, a *proposed* Linux gaming launcher/platform that would combine validated OpenRecomp execution paths with existing emulators and PC compatibility tools when appropriate

OpenRecomp OS is a future concept, **not an existing release or promise of universal game support**. Funding supports development effort, not guaranteed compatibility, features, or dates. No proprietary commercial games, firmware or keys are included.
